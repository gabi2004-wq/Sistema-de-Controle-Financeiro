# Sistema de Controle Financeiro

## Introdução
O Sistema de Controle Financeiro é uma aplicação web desenvolvida para auxiliar no gerenciamento de receitas e despesas, permitindo acompanhar a movimentação financeira de forma simples e organizada.

## Objetivo
Desenvolver uma ferramenta para registrar entradas e saídas financeiras, calcular o saldo disponível e facilitar o acompanhamento das finanças.

## Tecnologias utilizadas
- HTML5
- CSS3
- JavaScript
- LocalStorage

## Funcionalidades
- Cadastro de receitas.
- Cadastro de despesas.
- Cálculo automático do saldo.
- Indicadores financeiros.
- Histórico de movimentações.
- Exclusão de registros.
- Armazenamento de dados no navegador.

## Como executar
1. Baixe ou clone o repositório.
2. Abra a pasta do projeto.
3. Execute o arquivo index.html em um navegador.
